# Урок «Окружность. Центр и радиус» (5 класс)
Запуск: распакуйте архив и откройте `index.html` в Chrome/Edge/Safari (сервер не нужен). F11 или кнопка ⛶ — полный экран.
Управление: → или пробел — далее, ← — назад, Esc — закрыть подсказку. Экраны сами не переключаются.
Модель: 1 см = 46 ед. SVG; окружность x=x₀+r·cos t, y=y₀+r·sin t; расстояние d=√((x₂−x₁)²+(y₂−y₁)²).
Медиа: изображения в `assets/images/` (формат PNG), видео в `assets/videos/` (`.mov`). Видео запускаются только по кнопке; если файл не играет, показывается постер. При необходимости переименуйте/конвертируйте в mp4 и поправьте путь в `index.html`.
